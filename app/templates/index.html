How a customer is scored

The web app runs exactly the same code as the training notebooks

  1. CleanBlank TotalCharges → 0 for new customers
  2. EncodeScaler + one-hot fitted on train only
  3. MLP40 → 64 → 32 → 1, weighted BCE
  4. CalibratePlatt scaling: p is a real probability
  5. DecideOffer if p ≥ τ (τ* minimises cost)
  6. ExplainSHAP top-5 drivers per customer

Deployed model

How the campaign numbers are computed

  • Campaign cost(customers with p ≥ τ) × Coffer
  • Expected missed lossΣp < τ p × Clost
  • Do nothingΣ p × Clost
  • Net savingsdo nothing − (campaign + missed loss)
  • Offer is worth it whenp × Clost > Coffer ⇔ p > Coffer / Clost

Probabilities are Platt-calibrated, so Σp is the expected number of churners. Assumes an offer keeps a would-be churner.
